CRPO: Contract Release Purchase Order

A CRPO is a project-specific order issued under a Long-Term Agreement (LTA) with pre-qualified offshore contractors. The LTA sets the framework once. Each CRPO then commits a defined scope and value to one project, and that is where cost control starts.

LTA framework

Pre-qualified offshore contractors and agreed terms are in place before any project order.

CRPO issued

A project order is released under the LTA with its own scope and value.

Budget check

The CRPO value is checked against the project operational budget before it is committed.

Commitment tracking

The CRPO is recorded as a commitment, so committed cost and cost-to-complete stay current.

Review and flag

Invoices and variations are reviewed against the CRPO. Over-commitment and over-invoicing reach the project manager early.

My role as Project Controls on CRPO projects

  • Check each CRPO value against the operational budget before approval, and flag budget lines with no room left.
  • Record CRPOs as commitments next to PR and PO, so committed and forecast cost stay current.
  • Control change orders and variations raised against a CRPO.
  • Review subcontractor invoices against CRPO scope, value and progress.
  • Report committed, actual and forecast cost with cost-to-complete every month to the project manager and management.
